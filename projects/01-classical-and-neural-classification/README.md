# 01 · Classical and neural classification

This project follows image classification from distance-based methods through trainable neural networks. It includes k-nearest neighbors, linear SVM and softmax classifiers, hand-crafted image features, fully connected networks, common layers and optimization utilities.

Explore `classifiers/` for model code, then `layers.py`, `optim.py`, and `solver.py` for the training building blocks. The original class notebook prompts and submission materials are not included.
