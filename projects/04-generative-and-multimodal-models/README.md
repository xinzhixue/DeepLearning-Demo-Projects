# 04 · Generative and multimodal models

This project explores denoising diffusion and multimodal vision representations. The code includes Gaussian diffusion utilities, a U-Net denoiser, CLIP/DINO feature workflows, and training helpers.

Start with `gaussian_diffusion.py`, `unet.py`, and `clip_dino.py`. The original class notebook prompts, datasets, pretrained weights, and submission materials are not included.
