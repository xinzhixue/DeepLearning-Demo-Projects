# 02 · Convolutional networks

This project explores convolutional models and training techniques, including convolution/pooling operations, normalization, dropout, CNN classifiers, and recurrent components used in image-captioning experiments.

Start with `classifiers/cnn.py` and `layers.py`; supporting implementations live in `fast_layers.py`, `im2col.py`, and `rnn_layers_pytorch.py`. The original class notebook prompts, data, compiled extensions, and grading materials are not included.
